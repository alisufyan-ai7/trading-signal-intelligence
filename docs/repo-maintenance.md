# Repository Maintenance

- Update `docs/current-status.md` when a milestone/gate materially changes.
- Append decisions to `docs/decision-log.md`.
- Update `strategies/STATUS.md` only when evidence changes a strategy state.
- Every important experiment gets an ID under `research/experiments/`.
- Large raw market datasets stay outside Git; record reproducible retrieval parameters instead.
- Product implementation should not start consuming a new source until its source status is documented.
