## Three source-authority layers — never confuse them

1. **Published snapshot, potentially delayed:** for each published validation program use only allowlisted `validation_programs[].totals`, `health`, `mode`, `runtime_version` and `markets[]` fields. They are what the publisher last reported, not a fresh authenticated VPS scheduler probe. Compute snapshot age at read time and distinguish current (less than 90 minutes), delayed, unknown or future timestamps. Missing fields must stay null, not zero or healthy. A reported boundary violation must not enable a public signal.
2. **Isolated Postgres research projections, not source-authenticated:** read exact per-program/model/cohort/ingest-status *counts* from `vowsig_research_source_snapshots` and `vowsig_research_outcome_facts`. Display closed/open/no-trade/rejected/error and cost-flagged closed *database populations*, last observed and quarantined/verified/rejected flags. A database after-cost or completeness flag is NOT an independently reviewed track record. No win rate, P&L, profit factor or model ranking is computed from unapproved projections.
3. **Independent original-ledger source proof:** offline source files are absent from the reviewed GitHub branch and cannot be accessed through this chat. The repo contains read-only AI-v1 and S02 forward-ledger verifier algorithms. A new source-to-projection check requires an independently approved SHA256 of a frozen SQLite file, its exact external terminal record hash and full ledger row count, the sanitized cohort JSON SHA256 and exact outcome count, and separately declared program/version/cohort. It cryptographically verifies every original ledger row and all projected terminal-event row hashes, entity IDs and event types inside one source read transaction. An open projected signal is rejected if the original ledger contains a subsequent EXIT. No raw ledger payloads are output. This is **not** independent rights approval, historical cost arithmetic validation, full-cohort universe coverage, crypto K5 verification, or permission to publish metrics.

- Existing `GET /api/v2/admin/operations` retains backward-compatible fields and adds `owner_operational_diagnostics` with bounded current/delayed snapshot age, three registered shadow program statuses, missing/unknown counters and unverified runtime flags. Each market remains research-only and no new signal detail entitlement is granted.
- The member owner dashboard now includes **Runtime observability & operating boundaries**, **Model versions & projected lifecycle populations**, and **All-market reliability diagnostic**. All endpoints require the existing fresh owner MFA/role gate and return no-store private responses. These views are for operational investigations and show evidence limitations prominently.

## Exact-source original ledger cross-check contract

New `source_projection_reconciliation.py::check_source_projection_link` validates sanitized bundle and original terminal ledger hash/event identities. It admits only AI-v1 or S02 forward SQLite profiles; crypto expansion is explicitly rejected here pending its separate K5 verifier and source anchor protocol.

New read-only operator script: `scripts/vowsig_audit_original_ledger_vs_projection.py`. It **requires** all independently pinned fields: `--source-file` a frozen, private copy, `--profile` ai_v1 or s02_forward, `--expected-frozen-file-sha256`, `--source-head-sha256`, `--source-record-count`, `--bundle-file`, `--bundle-sha256`, `--outcome-count`, `--source-program`, `--model-version`, `--cohort`, and `--confirm READ_ONLY_FROZEN_SOURCE_RECONCILIATION`. It refuses symlinks, edited/mismatched files, invalid hashes, missing/extra source anchors or wrong lifecycle types, and outputs sanitized counts/hashes only. The original file SHA256 must match before and after. No source ledger constructor, schema mutation, VPS publisher, task scheduler, broker, cloud upload or database writer is invoked. Do not run it against a live mutable SQLite file; first create an independently approved frozen read-only source copy.

**Critical boundary:** even a PASS here shows only exact link membership to a pinned chain. An independent reviewer must also approve source rights, complete program/model/market/time coverage, cost methodology and each real shadow lifecycle; then issue a separate signed full-cohort attestation and eventual signed universe manifest. The platform's `verified_full_history` remains FALSE. Never convert these diagnostic counts into profit claims.
