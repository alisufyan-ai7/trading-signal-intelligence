# Data Provenance

Every research dataset/result should preserve:

- source (`exness_mt5_demo`, `binance_spot`, etc.)
- source symbol
- canonical symbol
- timeframe
- retrieval date/time
- requested date range
- connector/code commit
- relevant broker/server/product context
- cleaning/resampling rules

A result that cannot be traced back to its data source/config should not be used to promote a strategy.
