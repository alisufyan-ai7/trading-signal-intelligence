# Working Agreement

For future work on this project:

1. Read `PROJECT.md`, `docs/decision-log.md`, and relevant strategy/data documents before making material recommendations.
2. Write durable conclusions back to the repository.
3. Keep source-specific code behind adapters.
4. Prefer experiments with IDs and reproducible configs over ad-hoc notebook conclusions.
5. Treat legal/data-rights status conservatively until explicit evidence is recorded.
6. Keep all broker/exchange credentials out of Git.
7. Do not use unrelated repositories as context for this project.
