# Phase 0 Definition of Done

Phase 0 is complete when:

- MT5/Exness demo and Binance probes have been executed successfully.
- exact source symbols and history limitations are documented.
- normalized data and quality checks are reliable.
- a reproducible cost-aware backtest pipeline exists.
- at least S01 baseline has a recorded result (including rejection if it fails).
- production source-rights risks remain visible and do not get hidden by successful technical tests.
