# S02 Structure Breakout — v0.1

**Status:** IDEA  
**Created:** 2026-09-16

## Hypothesis

A closed-candle breakout beyond objectively defined recent structure, when accompanied by sufficient volatility/participation expansion and agreement with the broader regime, can exhibit continuation expectancy after costs.

## Guardrails before implementation

- Define structure algorithmically (no hand-drawn subjective levels).
- Separate true breakout from gap/event behavior.
- Evaluate close-confirmed baseline before intrabar entries.
- Prevent look-ahead when identifying swing levels.
- Test breakout distance normalized by ATR.
- Document spread/slippage sensitivity.

Detailed parameters will be frozen before the first experiment.
