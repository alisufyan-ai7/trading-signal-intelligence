# Project Context Isolation

This repository is the durable memory/source of truth for this project.

Rules:

- Do not use unrelated GitHub repositories as project context.
- Do not copy architectural decisions or strategy assumptions from unrelated projects unless explicitly introduced into this repository.
- When working through ChatGPT, prefer reading this repository's project files before making material changes.
- New major conclusions should be written back to this repository.
- Sensitive credentials/account identifiers are never stored here.

This policy reflects the project's requirement to keep its context isolated from other account-level projects.
