# G4 Customer Value Runbook

Run only after credible forward-test evidence exists.

1. Prototype the smallest signal-feed experience.
2. Show complete wins and losses, not curated examples.
3. Include concise reasoning/invalidation/risk.
4. Test user-controlled filters.
5. Recruit target traders and measure actual repeated use.
6. Test willingness to pay with a real price/commitment signal.
7. Use evidence to decide signal frequency, asset coverage and product tiering before building a large SaaS surface.
